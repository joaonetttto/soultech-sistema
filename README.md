# Desafio Front-End Soultech

## 📋 Descrição

Este projeto é uma aplicação web desenvolvida para o teste técnico de Front-End da Soultech. Ele permite:

- Login com autenticação JWT
- Visualização dos dados do usuário autenticado
- Cadastro de produtos via API
- Visualização dos produtos cadastrados

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- API da Soultech

---
